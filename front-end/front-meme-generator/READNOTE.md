### creer un projet react avec typescript et vite
npm create vite@latest portfolio_jumain

### installer axios
npm install axios

### Installer react-router-dom
npm install react-router-dom

### Installer Tailwind CSS et dépendances
npm install -D tailwindcss postcss autoprefixer

### Initialiser Tailwind
npx tailwindcss init -p

### mettre ceci dans le fichier css principal "index.css"
@import "tailwindcss";
